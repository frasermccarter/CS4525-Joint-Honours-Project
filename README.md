This is the codebase for the CS4525 Joint Honours Project - A Python-Based Engine for Music Scripting and Algorithmic Composition

All survey related material, including ethical approval and results can be found in the Survey Questions and Results Folder

For more information on how to operate and use the engine please refer to the user and maintentance manuals found in the Engine Manuals folder.

Example scripts can be found named as ex[1-6]_xxx.py.

Survey tasks are named task1.py, task2.py and task3.py and have been left for reference.

The GitHub repository for this project can be found at: https://github.com/frasermccarter/CS4525-Joint-Honours-Project
